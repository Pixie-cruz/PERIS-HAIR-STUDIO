# PERIS HAIR STUDIO 

A responsive website for **Peris Cut & Style Collective**, a salon and barbershop in Nairobi CBD, Kenya.

## Features

- Hero section with a clear call to action
- About the salon
- Services and pricing
- Customer voices (testimonials)
- Photo gallery
- Booking request form
- Contact details, opening hours and an embedded Google Map
- Black-and-gold design that works on phones, tablets and desktop

## Built with

- HTML
- CSS
- JavaScript
- Google Fonts (Fraunces and Work Sans)

## Live site

https://pixie-cruz.github.io/PERIS-HAIR-STUDIO/

## How to run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
